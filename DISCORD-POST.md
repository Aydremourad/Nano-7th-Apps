**Nano 7G apps for Mac**

I put the complete four-app Mac kit in its own GitHub repo. It has Calculator, Contacts, Chess, Golf, icons and the installer in one ZIP.

Download the ZIP from the README, unzip it, connect your nano, and run:

```bash
bash ~/Downloads/Nano7-Community-Mac-Kit-1.0/Start.command
```

Choose 1 to check the nano, then 2 to install.

Important: it only works with compatible **already modified** firmware; this isn't a jailbreak. The files came from a 2015 nano, and the included loader isn't hardware-tested on 2012 nanos. See the repo's README before installing.
