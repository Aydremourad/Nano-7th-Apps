# Original 2012 / 2013 iPod nano 7G

**Don't use the bundled startup loader on a 2012 nano unless you're prepared to test and recover it.** The exact loader in this kit came from a 2015 nano, and I haven't confirmed that it boots on the 2012 hardware.

## If your nano still has stock firmware

You cannot install these apps just by copying files to a stock nano. See the [ipod_sun_untethered releases](https://github.com/nfzerox/ipod_sun_untethered/releases) and the original [NanoApps setup](https://github.com/nfzerox/NanoApps). Read the original **2012-specific** release notes first. Their documented firmware-restore process uses Windows/iTunes and their app installer runs on Linux.

I don't have a verified Mac-only stock-to-homebrew firmware procedure that I'm comfortable distributing as a one-click installer.

## Already using compatible homebrew firmware?

Read the warning above. If you have a spare/recoverable device, a full backup, and know exactly which resident loader your firmware expects, you can inspect the kit using menu option 1 and run the offline test with option 5. **Menu option 2 replaces the resident/startup files**, not just app icons. That can conflict with your existing patched firmware and cause boot loops.

If all you want is the broader, tested upstream application collection, use [NanoApps](https://github.com/nfzerox/NanoApps) with its own resident instead of mixing it with this 2015-derived four-app bundle.

Both 2012 and 2015 nanos have the model number A1446, so **don't choose firmware based on A1446 alone**.
