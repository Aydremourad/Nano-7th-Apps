# 2015 iPod nano 7G

This installer is based on a working custom **2015 gold nano**. It is still a community beta; the exact packaged installer hasn't been physically tested across different users' nanos.

## If your nano already has working, compatible homebrew firmware

1. [Download the ZIP from this repository](Nano7-Community-Mac-Kit-1.0.zip?raw=1).
2. Unzip it and connect the nano to the Mac.
3. Open Terminal and run:

   ```bash
   bash ~/Downloads/Nano7-Community-Mac-Kit-1.0/Start.command
   ```

4. Choose 1 to inspect, 5 for an offline check, then 2 to install if you're sure the firmware uses a compatible startup hook.
5. Eject the nano. Open Music, go back Home, and check the icons.

If the launcher is different from the one in this ZIP, don't just mix them. This replaces resident/startup files and the app manifest, so incompatible versions can make apps disappear or even prevent booting. The backup/restore menu only works while the nano can mount.

## If your nano has stock firmware

You need a correctly patched **2015-specific** firmware first. The app ZIP cannot do that. See [ipod_sun_untethered releases](https://github.com/nfzerox/ipod_sun_untethered/releases) and the [NanoApps README](https://github.com/nfzerox/NanoApps). Upstream describes a Windows/iTunes firmware-restore step and Linux app install; this Mac kit starts **after** that part is set up.

**Never flash the 2012 firmware on the 2015 hardware.** A1446 and version 1.1.2 are not enough to identify the correct patched build.
